Жұмыс барысы

Issues, Kanban және GitHub Actions бойынша қадам-қадам нұсқаулық

1

GitHub Issues құру

Негізгі репозиторийге өтіп, Issues қойындысын ашыңыз және New issue батырмасын басыңыз. Тақырыбы мен сипаттамасын жазып (не істеу керек, қандай файлдар өзгереді, қабылдау критерийі), Issue-ды сақтаңыз. Әр қатысушы кемінде 1 Issue құруы тиіс.

2

Issue-ды орындаушыға тағайындау

Issue бетінде Assignees бөлімінен орындаушыны таңдаңыз, Labels арқылы белгі қосыңыз (bug, enhancement, documentation) және мерзімі мен түсіндірмесін жазыңыз.

3

GitHub Projects (Kanban) тақтасын құру

Репозиторийден Projects → New project таңдап, Board түрін таңдаңыз. To Do, In Progress, Review және Done бағандарын жасап, Issues-ті тиісті бағандарға сүйреп орналастырыңыз.

4

Issue негізінде тармақ (branch) құру

Issue бетінде Create a branch for this issue батырмасын басыңыз. GitHub жаңа тармақты автоматты түрде жасайды. Локалды репозиторийде оны жүктеңіз:

git fetch
git checkout <issue-branch-name>
5

Тапсырманы орындау және Pull Request жасау

Issue талаптарына сай өзгерістер енгізіп, оларды сақтаңыз және жіберіңіз:

git add .
git commit -m "Issue #X орындалды"
git push origin <branch-name>
6

Pull Request сипаттамасы

GitHub-та Pull Request жасаңыз. Сипаттамасына мына жолды жазсаңыз, Pull Request біріктірілгенде Issue автоматты түрде жабылады:

Closes #X
7

GitHub Actions арқылы автоматтандыру

Репозиторийде .github/workflows/html-check.yml файлын жасап, ішіне төмендегі мазмұнды жазыңыз:

name: HTML Check

on: [push, pull_request]

jobs:
  validate-html:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: HTML validation
        run: echo "HTML файлдары тексерілді"
8

Workflow тексеру

GitHub-та Actions қойындысына өтіңіз. Pull Request ашқанда немесе push жасағанда workflow іске қосылғанын тексеріңіз. Жасыл белгі тапсырма сәтті орындалғанын білдіреді.

Тапсырма

Жұмыс соңында орындалуы тиіс

  • Репозиторийде кемінде 3 Issue құрыңыз.
  • Projects (Kanban) тақтасында тапсырмаларды орналастырыңыз.
  • Бір Issue-ды branch → commit → Pull Request арқылы орындаңыз.
  • GitHub Actions workflow-ты іске қосыңыз.
  • Pull Request сәтті біріктірілуі тиіс.
